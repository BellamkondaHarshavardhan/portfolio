    NexusIQ
    multi-agent copilot

    NexusIQ: Enterprise Multi-Agent AI Copilot

    Teams keep answers in documents, databases and tools. NexusIQ uses a supervisor agent to send each question to the right agent, then returns one cited answer.

    PythonLangGraphLangChainOpenAI APIChromaDBRAGMCPText-to-SQLSQLiteStreamlitDocker
    GitHub repository
    View project details

    Architecture

    Question, then Supervisor, then the RAG agent, SQL agent or tool-calling agent (run in parallel for combined questions), then a self-critic check, then a cited answer.

    Key features

    • Hybrid RAG on ChromaDB: vector search plus BM25, merged with Reciprocal Rank Fusion and heading-aware chunking.
    • Secure text-to-SQL agent with sqlglot query validation, a read-only connection, role-based column access and self-correction of failed queries.
    • MCP server exposing 5 tools.
    • Prompt-injection and PII guardrails.
    • Streamlit and Chainlit interfaces with live agent traces and LangSmith tracing.

    Try hybrid retrieval

    Illustrative documents for the query “refund window”. Switch a retriever off or change k to see Reciprocal Rank Fusion re-rank the results.

      Dibe Retinal: Explainable AI for Diabetic Retinopathy

      Screening retinal images by hand is slow, and a bare prediction is hard to trust. This platform grades severity from fundus images and highlights the regions behind each result.

      PythonTensorFlowKerasResNet50Grad-CAMOpenCVFlaskMySQLHTML, CSS, JavaScript
      GitHub repository
      View project details

      Architecture

      Fundus image, then ResNet50 transfer learning, then a five-level severity prediction with a Grad-CAM heatmap, then a PDF report saved to the prediction history.

      Solution

      • ResNet50 transfer learning classifies images into five severity levels.
      • Grad-CAM heatmaps show what the model looked at.

      Key features

      • User authentication, image upload and AI inference.
      • Prediction history tracking.
      • PDF reports with risk assessment, confidence score, precautions and diet recommendations.
